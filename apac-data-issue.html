APAC Data Issue — Dashboard Action Guide

Training & Certification · FY27 · For APAC delivery leaders and Salesforce admin

Why APAC instructors are missing from the dashboard This is not a data entry problem — it is a structural ownership issue in Salesforce. APAC (and LATAM) campaigns are created and owned by the TandC Integrations system account, not the individual instructor. The utilization report can only find campaigns through Campaign Owner, so no APAC campaigns surface regardless of what instructor names are in the report filters.

1 What's happening

The report type joins three objects to get from instructor → campaign. For AMER/EMEA this works. For APAC it breaks at the last step.

The instructor is recorded on each campaign — in a custom field called Campaign.Instructor__c — but the report type does not read from that field. It only reads Campaign Owner.

Current workaround APAC utilization data is loaded from the Google Sheet (FY27 Event Util Days Matrix) as monthly aggregates. This is why APAC instructors appear in the main utilization views but are missing from per-campaign drill-downs and the By Cloud breakdown. If the Google Sheet is not being maintained, those instructors show zero in the dashboard.

2 What to ask APAC leaders

Share these four asks with Affa Khatoon, Mohina Sheikh, and their counterparts covering India-based instructors. The goal is to ensure data is accurate now and ready for a structural fix later.

  • 1
    Is the Instructor__c field populated on every campaign your team delivers?
    Spot-check 5–10 recent campaigns in Salesforce. Open the Campaign record and confirm the Instructor field has the correct name. This is the data that will feed any future structural fix — if it's blank now, fixing the report type still won't capture the hours.
  • 2
    Is the FY27 Event Util Days Matrix Google Sheet being updated monthly for every instructor on your team?
    This is the only source feeding APAC data into the dashboard right now. Every instructor — including all India-based instructors on Affa's and Mohina's teams — must have their delivery days entered. A blank month = zero hours in the dashboard.
  • 3
    Do all your instructors have an active, complete Contact record in Salesforce?
    Each instructor needs all four flags set on their Contact record: Instructor Status = Certified Instructor, Instructor Type = Salesforce Employee, Account = salesforce.com, Active Contact = true. Missing any one of these will exclude them from the dashboard — even after the structural fix is in place.
  • 4
    Are campaign Start Time, End Time, and Address fields being populated when campaigns are created?
    These fields drive the hours calculation: Start/End Time → daily hours; Address → travel hours (16 hrs if onsite, 0 if virtual). If they're blank now, fixing the report type will surface the campaigns but show 0 hours. It's worth getting into good habits now so the data is clean when the fix lands.

3 Fix options

Three paths to resolve the structural issue permanently. Option A is recommended.

Option What it involves Effort Risk
A — New custom report type Recommended Create a report type in Salesforce Setup that joins Campaign → Contact via Instructor__c, then Contact → User. All APAC/LATAM campaigns will then be findable by instructor name. No changes to any automation. Medium — Salesforce admin needed Low
B — Change Campaign Owner Update the TandC Integrations automation to set Campaign Owner = the instructor's User record instead of (or alongside) the Instructor__c field. Makes the existing report type work without changes. Medium–High Medium — may affect other automation that depends on TandC Integrations as owner
C — Keep Google Sheet Current Continue using the FY27 Event Util Days Matrix as the APAC/LATAM data source. Works but limited — no per-campaign detail, no cloud breakdown, dependent on manual updates. Low — already in place Low (data risk if Sheet not maintained)
