Course Code → Cloud Mapping Reference

Training & Certification · FY27 · Source of truth for cloud assignment in the By Language dashboard tab

This table controls how every Authorization course code is assigned to a cloud in the By Language, By Cloud, and By Subco tabs. The authoritative field in T&C Salesforce is Course__c.Primary_Product__c on each Course record. Other is a permanent live category — any prefix not explicitly mapped stays there and can be tracked, confirmed, or left as-is. SF Count = total Authorization records in T&C Salesforce org for that prefix.
Authoritative Salesforce report: Course Code → Cloud Mapping Reference  ·  ID: 00OdK000003qKfFUAU  ·  Folder: Global Authorization Reports
Grouped by Primary Product → Course Name. Open this report in the T&C org to see every cert grouped by cloud, and to spot courses under the (blank) bucket that still need Primary_Product__c set. This report is the single source of truth — update it whenever a course's cloud changes.

How to Update the Mapping

Preferred path — update Course__c.Primary_Product__c in Salesforce: Set the Primary Product field on the Course record in the T&C org. The Course Code → Cloud Mapping Reference report (ID: 00OdK000003qKfFUAU) will immediately reflect the change. On the next dashboard data refresh, that course will move out of Other into the correct cloud.
Fallback — manual prefix mapping: If the Salesforce field cannot be updated right now, tell the dashboard owner: "map PREFIX to [Cloud Name]". This adds a one-line rule to the prefix table in index.html → push → live in ~1 minute. Note: the Salesforce field should still be updated for long-term consistency.
  1. Open the Course Code → Cloud Mapping Reference report in T&C Salesforce — look for the (blank) grouping
  2. Set Course__c.Primary_Product__c on each course to the correct cloud
  3. Rebuild and republish the dashboard — the Other category will shrink accordingly
  4. Update this page: move the row from "Needs Confirmation" to "Confirmed Mappings", update the SF Count
